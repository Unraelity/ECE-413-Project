About Heart Track

Heart Track is a low-cost IoT and Web Application designed to help users track heart rate and blood oxygen saturation. A sensor device collects measurements and can remind users to take readings on the website at a schedule they can choose. The Heart Track dashboard then displays weekly and daily trends so users can review their data anytime. The web app is built with responsive design, making it easy to use on desktop, tablet, and mobile screens.
