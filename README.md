## Heart Track (ECE 413 Final Project)
Heart Track is an IoT and Web platform that collects heart-rate (HR) and SpO2 readings from a Particle P2 + MAX30105 sensor, forwards the data to a Node/Express server via a Particle Webhook Integration, stores it in MongoDB, and displays it on a web dashboard.
